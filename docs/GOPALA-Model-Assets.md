# Prototype buildings and worker models

The Kathmandu view uses Kenney Survival Kit 2.0 timber structures and Blocky Characters 2.0 character-a from the locally downloaded packs. Both are CC0-1.0. These are temporary stylized prototypes, not historically verified Nepali buildings or clothing. Canonical sources: https://kenney.nl/assets/survival-kit and https://kenney.nl/assets/blocky-characters.

Selected GLBs, their external texture dependencies and the original License.txt were packaged under `.tools/asset_packages`, hash-verified, then admitted into `game/assets/models/kenney_survival` and `kenney_workers`. Each source receipt records the original archive hash, canonical URL and a selected-file SHA-256 roster. Vendored bytes remain unmodified. The optional game-dev CLI was unavailable; no skill CLI verification receipt is claimed.

Worker model height is 1.75 metres measured in its static pose, using an unanimated normalization wrapper so native animation tracks cannot reset its unit conversion. Idle, walking and pickup animations observe authoritative simulation states; pause and simulation speed control playback. Animation never modifies inventories or construction. Carry markers remain physical-size resource indicators. The worker picking capsule and entity adapter remain independent of the visible model.

Every building definition receives a roofed timber shelter, with canvas walls for dwellings, crates for stockpiles/timber camps and a barrel for water points. This is visual differentiation, not implementation of additional building functions. Roof and walls are uniformly fitted to both the actual logical footprint and the 2.5-metre maximum height. Compact structures can occupy less than the logical plot; the reservation and picking bounds retain the entire plot. The blueprint and material-wait stage markers remain, the timber frame appears during construction, and the roofed model appears only on completion. Model bottoms stay grounded as the stage marker height changes.

`python3 tools/verify.py` runs model source/hash checks, worker normalization and animation-state tests, each building's normal/rotated footprint and stage visibility checks, alongside existing picking, construction, collection, delivery and conservation suites. `reports/model-asset-audit.json` is regenerated with measured dimensions. Real renderer captures are in `reports/manual/asset-replacement-close.png` and `asset-replacement-default.png`. These are visual evidence, not performance or final-art acceptance.
