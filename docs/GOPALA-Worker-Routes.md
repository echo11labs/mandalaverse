# Worker routing slice

The Kathmandu game configures four-neighbour AStarGrid2D routing using the same two-metre logical coordinate conversion and occupied/reserved building cells as placement. The navigation rectangle extends the 48x48 planning bounds by 80 metres on each side, covering the nearby seeded resources without enlarging placement cells. Water ribbons and terrain steeper than 35 degrees are blocked when the scene configures its static navigation surface. Scenario camp plots now have occupancy claims as well as placed buildings.

Workers traverse cached waypoints with a distance budget based on their 1.4 m/s speed and the prototype's configured logical tick duration. Occupancy changes invalidate cached routes, which replan before moving through a new obstruction. Routes start at the current cell centre, preventing corner cuts from off-centre positions. Debug moves reject solid/out-of-bounds/unreachable goals. Delivery and building work choose the shortest reachable free perimeter cell beside the target claim rather than entering its footprint. Declared entrance preference, road costs, bridges and long-range regional routes remain future work.

A gather request that cannot reach its source releases its reservation and task ownership. A route blocked before pickup cancels safely. A blocked delivery keeps goods carried and retries after occupancy changes, without crediting the ledger remotely. Construction routes use the same blocked/retry behaviour for material pickup, delivery, work and cancellation returns. The HUD reports route failures and obstructed carriers. Placement rejects blocked terrain cells and plots containing a worker while navigation is enabled; debug spawning also rejects blocked cells.

Navigation is configured by the playable Kathmandu scene. Small older unit fixtures that do not configure a navigation surface retain their direct-movement fixture behaviour; they do not constitute routing coverage. `run_route_tests.gd` explicitly enables routes and covers detours, solid/out-of-bounds rejection, invalidation, blocked pickup reservation release, blocked delivery recovery/conservation, all live seeded deposits, scenario occupancy, safe placement and an entire live four-load stockpile construction cycle. Existing live stone/timber input tests also run with navigation enabled. Animation observes each waypoint without owning movement or goods.

Static terrain is sampled once at navigation configuration. Occupancy rebuilding preserves those blocked terrain cells. Session reset clears route caches; source meshes, scenery culling and camera movement have no authority over navigation. This is a local routing slice, not completion of G-008/G-009, save/load, capacity handling or the fifteen-minute settlement acceptance.
